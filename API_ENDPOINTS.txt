

================================================================================
MARCAS
================================================================================

GET /marcas/autocomplete?q=X
-----------------------------
Sugestões rápidas de nome de marca (mín. 2 caracteres, máx. 15 resultados).
Resposta: ["NATURA", "NATURA EKOS", ...]

--------------------------------------------------------------------------------

GET /marcas/buscar
------------------
Parâmetros:
  nome               string        Busca full-text no nome da marca
  titular            string        Nome do titular (parcial)
  processo           string        Número exato do processo
  classe             string        Classe Nice — único (25) ou múltiplos (25,35,42)
  status             string        Texto do despacho (parcial)
  vigente            true|false    Filtra por vigência atual
  situacao           string        Situação canônica calculada server-side:
                                   vigor | analise | recurso | indeferido | extinto
  uf                 string        UF do titular (ex: SP)
  pais               string        País do titular (ex: BR)
  tipo               string        Tipo da marca (ex: Mista)
  natureza           string        Natureza (ex: Produtos)
  procurador         string        Nome do procurador (parcial)
  despacho_codigo    string        Código exato do despacho (ex: IPAS029)
  despacho_categoria string        Categoria do despacho (ex: concessao, exame, recurso)
  deposito_de        YYYY-MM-DD    Data de depósito — início
  deposito_ate       YYYY-MM-DD    Data de depósito — fim
  concessao_de       YYYY-MM-DD    Data de concessão — início
  concessao_ate      YYYY-MM-DD    Data de concessão — fim
  vigencia_de        YYYY-MM-DD    Data de vigência — início
  vigencia_ate       YYYY-MM-DD    Data de vigência — fim
  sort_by            string        nome_marca | data_deposito | data_concessao |
                                   data_vigencia | titular | updated_at
  sort_order         string        asc | desc (padrão: desc)
  page               number        Página (padrão: 1)
  limit              number        Itens por página — máx 100 (padrão: 20)
  sem_contagem       true          Omite o total para resposta mais rápida
  formato            csv           Retorna arquivo CSV em vez de JSON

================================================================================
OBSERVAÇÕES GERAIS
================================================================================

- Todos os endpoints de listagem aceitam ?formato=csv para exportar direto
- Paginação padrão: page=1, limit=20 (máx 100)
- Datas sempre no formato YYYY-MM-DD
- Campos calculados presentes em todas as listagens:
    vigente              boolean   true se data_vigencia > hoje
    dias_para_vencer     integer   dias até o vencimento (negativo = vencida)
    despacho_descricao   string    descrição oficial do código de despacho
    despacho_categoria   string    categoria raw do despacho: deposito, exame, publicacao,
                                   recurso, concessao, renovacao, extincao, nulidade, anotacao
                                   ATENÇÃO: IPAS024 (Indeferimento) tem categoria='exame' —
                                   use situacao_calculada para classificação correta
    situacao_calculada   string    situação canônica calculada server-side, livre de
                                   ambiguidades de categoria. Valores possíveis:
                                     vigor      — registro concedido e vigente
                                     analise    — em exame, publicado, depositado etc.
                                     recurso    — aguardando recurso ou nulidade
                                     indeferido — pedido indeferido (todos os códigos)
                                     extinto    — extinto, caducado ou arquivado
    classe_descricoes    array     nomes por extenso das classes Nice

- Autenticação: se API_KEY estiver configurada no servidor, envie o header:
    X-API-Key: <sua-chave>

- CORS: origens aceitas configuradas via CORS_ORIGINS no servidor
